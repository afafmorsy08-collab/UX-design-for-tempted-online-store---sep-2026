# TEMPTED — React E-Commerce Storefront (UX-design)-sep 2026


TEMPTED is a modern e-commerce storefront concept created for a women’s fashion brand, combining a refined editorial aesthetic with a smooth and engaging online shopping experience.

The project is designed with a dark, sophisticated visual identity, complemented by warm wine-red accents, elegant typography, and a fully responsive RTL Arabic interface. The experience focuses on clear product presentation, intuitive navigation, and interactive elements that make browsing and shopping feel seamless across desktop and mobile devices.

Beyond the visual design, the storefront includes functional interactions such as product wishlist toggling, cart item counting, an AI shopping-assistant interface, newsletter subscription, category browsing, and responsive navigation. These interactions are powered by React state, making the project more than a static visual mockup.

The project was built using React 18, TypeScript, Tailwind CSS v4, and Iconify React, following a component-based approach that keeps the interface scalable, organized, and easy to customize.

The overall goal is to create a polished digital fashion experience that balances visual storytelling, usability, accessibility, and modern front-end development practices.
